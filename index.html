Type-2 hypervisor for Windows on AMD SVM

              
  • C++
  • C
  • x86-64 asm
  • WDK
  • AMD SVM

              
// VMCB · VMRUN · VM exits · instruction interception · kernel-mode driver · IOCTL

            

            

              
A hypervisor for Windows that uses AMD's Secure Virtual Machine extensions to run a guest under its control. Written from scratch in C++, C and assembly.

              
    
                
  • Sets up the VMCB and manages guest state across VM entry and exit.
    • 
                
  • Intercepts guest instructions and handles the resulting VM exits.
    • 
                
  • Runs as a Windows kernel-mode driver, controlled from user mode through IOCTL interfaces.
    • 
              

              
  user mode    │  ctl.exe ──IOCTL──┐
 ──────────────┼───────────────────▼──────────
  kernel mode  │  driver.sys → VMRUN ⇄ #VMEXIT
 ──────────────┼──────────────────────────────
  hardware     │  AMD-V (SVM) · VMCB

                TheMonitor↗
                $ open github.com/monarch-69/TheMonitor
              
              

              
Distributed server monitoring suite

              
  • C++17
  • Python
  • FastAPI
  • Kafka
  • Docker
  • React + TS

              
// procfs · syscalls · libcurl · Kafka consumer groups · multithreading · Argon2id · Ed25519

            

            

              
An open-source platform that collects live telemetry from many Linux servers and streams it through an event pipeline to a web dashboard.

              
    
                
  • C++17 telemetry agent reads CPU and memory data from /proc via syscalls and ships it over HTTP with libcurl.
    • 
                
  • Moved ingestion from one Docker container per account to a Kafka event pipeline with consumer groups, so it scales with the number of servers.
    • 
                
  • Multithreaded FastAPI backend with Argon2id password hashing and Ed25519 challenge-response auth for agents.
    • 
                
  • React + TypeScript dashboard.
    • 
              

              
 agent.cpp  ← /proc/stat, /proc/meminfo
     │ libcurl
     ▼
 FastAPI ──▶ Kafka ──▶ consumers ──▶ Postgres
                                 └──▶ React UI
